# Task Management Board

This project is a starter React + Vite task management board created for future task-card, drag/drop, and localStorage functionality.

## Features planned

- Multiple task columns
- Add, edit, and delete tasks
- Move tasks between columns
- LocalStorage persistence
- Responsive UI

## Install

```bash
npm install
```

## Run locally

```bash
npm run dev
```

## Build for production

```bash
npm run build
```

## Project structure

- `src/components` for the board UI pieces
- `src/context` for the React context state
- `src/hooks` for custom hooks like localStorage
- `src/styles` for component styling
